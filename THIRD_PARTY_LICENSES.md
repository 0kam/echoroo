# Third-Party Licenses

Echoroo itself is licensed under the **GNU GPL v3** (see [LICENSE](LICENSE)).
This document lists the **direct runtime dependencies** of each application and
their licenses.

> **Scope & accuracy.** Only direct runtime dependencies are listed (test /
> lint / build tooling is omitted). License identifiers below are best-effort
> [SPDX](https://spdx.org/licenses/) values looked up from the upstream
> projects; where a value could not be confidently determined it is marked
> *see upstream*. Always confirm against the version actually installed.
>
> **Transitive dependencies** pulled in by the packages below retain their own
> licenses and are not enumerated here. Use `uv export` (backend) or
> `npm ls` / a license scanner (frontend) to produce a full transitive report.
>
> **Machine-learning model weights** (BirdNET, Perch) are downloaded at runtime
> and are **not** Python/npm dependencies — their licensing is described
> separately in [MODEL_LICENSES.md](MODEL_LICENSES.md).

## Bundled reference data — `apps/api/echoroo/data/`

Unlike the packages above, these are **data files physically shipped inside
the Python package** (not downloaded at runtime), so their attribution
requirements travel with every Echoroo distribution. They are regenerated by
`apps/api/scripts/build_vernacular_bundle.py`; each bundle carries a
`*.meta.json` sidecar recording the upstream version, license and retrieval
date.

### IOC World Bird List v15.2 — Multilingual Version

- **Bundled as:** `echoroo/data/vernacular/ioc_ja.csv` (+ `ioc_ja.meta.json`)
- **What is bundled:** the **Japanese vernacular names only**, paired with the
  IOC scientific name (10,722 rows). No other language column, and none of the
  workbook's taxonomic/annotation columns, are redistributed.
- **License:** CC BY 3.0 Unported —
  <https://creativecommons.org/licenses/by/3.0/>
- **Citation:** Gill F, D Donsker & P Rasmussen (Eds). 2026. IOC World Bird
  List (v15.2). doi:[10.14344/IOC.ML.15.2](https://doi.org/10.14344/IOC.ML.15.2)
- **Source:** <https://www.worldbirdnames.org/> (file:
  `Multiling IOC 15.2.xlsx`)

### AviList v2025b — The Global Avian Checklist (extended)

- **Bundled as:** `echoroo/data/vernacular/birdnet_crosswalk.csv`
  (+ `birdnet_crosswalk.meta.json`)
- **What is bundled:** a **scientific-name crosswalk only** — for each BirdNET
  V2.4 label, the matching AviList `Scientific_name`, `AvibaseID` and
  `Species_code_Cornell_Lab`. English names, range/IUCN/authority columns and
  bibliographic fields are **not** redistributed. The crosswalk exists because
  BirdNET labels follow eBird/Clements while the IOC list follows its own
  taxonomy, so recent genus revisions (e.g. `Accipiter gularis` →
  `Tachyspiza gularis`) would otherwise drop a Japanese name.
- **License:** CC BY 4.0 — <https://creativecommons.org/licenses/by/4.0/>
- **Citation:** AviList Core Team. 2026. AviList: The Global Avian Checklist,
  v2025b. doi:[10.2173/avilist.v2025b](https://doi.org/10.2173/avilist.v2025b)
- **Source:** <https://www.avilist.org/>

### Not bundled: BirdNET-Analyzer translated label files

BirdNET-Analyzer ships its own translated label sets (including Japanese) and
an eBird taxonomy-code mapping under **CC BY-NC-SA**, whose non-commercial
clause is incompatible with Echoroo's GPL-3.0 distribution. **None of those
files are bundled or derived from.** Only the *English* BirdNET V2.4 label list
(the model's own class names, already required to interpret model output) is
read at build time to enumerate which taxa need a crosswalk row; the resulting
mapping is built from AviList data. BirdNET model weights themselves are
described in [MODEL_LICENSES.md](MODEL_LICENSES.md).
